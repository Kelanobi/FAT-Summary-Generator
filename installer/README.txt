Qualitrol FAT Summary - Windows Install Package

Install:
  Double-click "Install Qualitrol FAT Summary.cmd"

What it does:
  - Installs the app to %LOCALAPPDATA%\Programs\Qualitrol FAT Summary
  - Creates a Start Menu shortcut
  - Creates a Desktop shortcut
  - Keeps all processing local to the machine

Uninstall:
  Run Uninstall.ps1 from the installed folder, or run the Uninstall.ps1 included here.

Notes:
  - Chrome or Edge is recommended for best PDF rendering.
  - If browser rendering is unavailable, the app falls back to a simpler native PDF renderer.
